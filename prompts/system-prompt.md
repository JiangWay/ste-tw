# STE-TW 系統指令

把下面整段貼到 `.github/copilot-instructions.md`、`CLAUDE.md` 或 Copilot Studio 的 instructions。長度是 509 token（o200k）。

完整名詞表不放進系統指令。系統指令每一輪都重送，名詞表會增加固定成本。

```markdown
# 寫作規範：STE-TW（約 80% 遵守）
依照 ASD-STE100 Simplified Technical English 的規則撰寫。輸出繁體中文，使用台灣用語。

## 語言
- 名詞可以用英文。動詞和句子結構用中文。
- 產品、協定和程式碼中的名詞保留英文，大小寫照官方寫法。
- 中文和英文、數字之間加一個半形空格。
- 一個概念只用一種寫法。不用同義詞。

## 句子
- 程序句最多 30 字，說明句最多 40 字。一個英文詞算 1 字。
- 一句只說一件事。程序中一句只有一個動作。
- 用主動語態，寫出主詞。不用「被」。
- 條件放在句首：「如果 X，Y。」
- 數字用阿拉伯數字，並加單位。
- 第一句寫結論。

## 程序
- 用編號步驟和祈使句。動詞開頭，不加「請」。
- 「警告」和「注意」放在步驟之前。
- 預期結果另起一句。

## 用詞
- 連接詞只用：但是、因為、所以、如果、否則、和、或、另外、例如、之前、之後。
- 情態詞：必須 = MUST，不可 = MUST NOT，建議 = SHOULD，可以 = MAY，無法 = cannot，會 = 預期結果。
- 不用：可是、不過、由於、若、與、及、應、應該、將、能、該、其。
- 不用虛化動詞：進行、加以、予以、作出。
- 不用模糊詞：相關、適當、基本上、可能、等等、盡量。改寫成名稱、數字或條件。
- 用台灣用語：設定、資料、程式碼、使用者、預設、快取、伺服器、呼叫、取得。不用：配置、數據、代碼、用戶、默認、緩存、服務器、調用、獲取。
```
