# STE-TW 常用詞語選用表

每個意思只核准一個詞。不核准的詞不一定錯，但是統一之後，人、LLM 和 lint 工具都可以用一個詞對應一個意思。

選詞依據：台灣常用、意思單一、不帶情緒、不是文言。

## 1. 連接詞

| 核准 | 意思 | 不用 | 理由 |
| --- | --- | --- | --- |
| 但是 | 轉折 | 可是、不過、然而、但、只是 | 「可是」偏口語，常帶抱怨語氣。「不過」語氣弱，讀者會低估轉折。「然而」偏文言。「只是」也有「僅僅是」的意思 |
| 因為 | 原因 | 由於、因、基於、鑑於 | 「由於」「鑑於」是公文用語。「基於」也有「以…為基礎」的意思 |
| 所以 | 結果 | 因此、因而、故、於是、從而 | 「故」是文言。「於是」帶時間先後，不一定是因果 |
| 如果 | 條件 | 若、假如、倘若、要是、如、…的話 | 「如」也可能是「例如」。句尾「的話」是贅字 |
| 否則 | 條件不成立時 | 不然、要不然 | 「不然」偏口語 |
| 當…時 | 時間點 | 在…的時候、於…時、每當 | 「在…的時候」多字，意思相同 |
| 之前 / 之後 | 時間前後 | 以前、以後、前、後 | 單字「前」「後」也可能是位置 |
| 然後 | 時間順序（說明文字） | 接著、隨後、再來 | 程序用編號，不用「然後」 |
| 和 | 名詞並列 | 與、及、以及、跟、同、暨 | 「跟」偏口語。「及」「暨」是書面語。動詞不用「和」並列，拆成兩句 |
| 或 | 任一個 | 或者、或是、抑或、還是 | 「還是」只用在問句 |
| 另外 | 補充新的一點 | 此外、再者、而且、並且 | 「再者」偏文言 |
| 也 | 相同情況 | 亦、同樣地 | 「亦」是文言 |
| 例如 | 舉例 | 比如、譬如、諸如、像是 | 「諸如」偏文言。「像是」也有「類似」的意思 |
| 也就是 | 換句話說 | 即、亦即、意即、換句話說 | 「即」也有「馬上」的意思 |
| 只有…才 | 必要條件 | 唯有、僅…方 | 「方」是文言 |

## 2. 情態詞（對應 RFC 2119 和 OpenSpec）

規格文件中，這一組詞一定要嚴格使用。對應詞彙讓繁中規格和英文 `SHALL` / `SHOULD` 一對一。

| 核准 | 對應 | 不用 | 理由 |
| --- | --- | --- | --- |
| 必須 | MUST / SHALL | 應、應該、需、需要、務必、得 | 「應」在台灣法規是 SHALL，工程師常理解為 SHOULD，有歧義。「得」可讀作 de、déi 或 děi |
| 不可 | MUST NOT / SHALL NOT | 不得、禁止、不要、勿、別、不能 | 「不能」可以是「做不到」或「不允許」 |
| 建議 | SHOULD | 最好、宜、應當 | 「最好」偏口語 |
| 不建議 | SHOULD NOT | 最好不要、不宜 | — |
| 可以 | MAY（允許） | 能、能夠、可、得以 | 「能」同時表示能力和允許 |
| 無法 | cannot（做不到） | 不能、沒辦法、未能 | 和「不可」區分：無法是能力，不可是規定 |
| 會 | 預期的系統行為 | 將、將會、勢必 | 「將」偏書面且多餘 |

## 3. 常用動詞

| 核准 | 意思 | 不用 | 理由 |
| --- | --- | --- | --- |
| 使用 | use | 利用、運用、採用 | 「用」可作介詞（用 code 格式） |
| 設定 | configure、set；也作名詞 | 配置、設置、組態 | 「配置」「設置」是大陸用語 |
| 檢查 | check（查看內容） | 查看、檢視、核對 | — |
| 確認 | make sure（確保狀態正確） | 確定、確保、核實 | 和「檢查」區分：確認要有預期結果 |
| 啟動 / 停止 | 服務或程式 start / stop | 運行、終止、中止、關掉 | — |
| 重新啟動 | restart 服務或 Pod | 重啟、重開 | 「重新開機」只用於主機 reboot |
| 啟用 / 停用 | 功能 enable / disable | 激活、開通、禁用 | 「激活」是大陸用語 |
| 開啟 / 關閉 | 檔案、頁面、連線 open / close | 打開、關掉 | 不用「關閉」表示停用功能 |
| 建立 | create 資源 | 創建、新建、生成 | 「創建」是大陸用語 |
| 新增 | add 項目到清單 | 添加、加入 | — |
| 刪除 | delete（資料消失） | 刪掉、清除、砍掉 | — |
| 移除 | remove（從集合拿掉，資料仍在） | 剔除、拿掉 | 和「刪除」區分，例如 Pod 從 endpoint 移除 |
| 修改 | modify 內容 | 更改、改動、調整、變更 | 「變更」只用於「變更管理」 |
| 更新 | update 到新版或新值 | 刷新、更替 | 「升級」只用於版本 upgrade |
| 執行 | run、execute | 運行、跑、實行 | 「運行」是大陸用語 |
| 部署 | deploy（動詞） | 佈署、上版 | 「上線」只用於正式開放使用 |
| 呼叫 | call API 或函式 | 調用、call | 「調用」是大陸用語 |
| 傳送 / 回傳 | send / return | 發送、傳遞、返回、傳回 | 「返回」是大陸用語 |
| 取得 | get、obtain | 獲取、拿到、獲得 | 「獲取」是大陸用語 |
| 發生 | 錯誤或事件 occur | 出現、產生、報錯 | 「產生」用於 generate |
| 失敗 | fail | 出錯、掛掉、異常（動詞） | 「掛掉」是口語 |
| 顯示 | show、display | 呈現、展示、秀出 | — |
| 按 | 按 UI 按鈕 | 點擊、點選、點 | — |
| 輸入 | 在欄位中輸入值 | 鍵入、填入、填寫 | — |

## 4. 否定、指稱與人稱

| 核准 | 意思 | 不用 | 理由 |
| --- | --- | --- | --- |
| 不 | 動作或一般否定 | — | — |
| 未 | 狀態還沒發生（未設定、未授權） | 沒有設定、尚未 | 狀態用「未」，和「沒有」區分 |
| 沒有 | 不存在 | 無 | 「無」只用在「無法」 |
| 這個 | 指前一句的名詞 | 該、此、其、本 | 「該」也有「應該」的意思 |
| （不寫主詞） | 內部文件的指令 | 你、您、請 | 祈使句已經清楚 |
| 您 / 請 | 對客戶的訊息和 UI | 你 | 對外保持禮貌 |

## 5. 刪除即可的詞

這些詞沒有替代詞。刪除它們，或寫出具體內容。

| 不用 | 處理方式 |
| --- | --- |
| 進行、作出、加以、予以 | 刪除，把後面的名詞改回動詞 |
| 相關、有關（模糊用法） | 寫出具體名稱 |
| 適當、適度、一定程度 | 寫出數字或條件 |
| 基本上、原則上、一般來說 | 刪除；有例外就寫出例外 |
| 可能（描述系統行為） | 改用「如果…」寫出條件 |
| 等、等等 | 列出全部，或用「例如」 |
| 儘量、盡可能 | 寫出目標值 |
| 一下、喔、啦、哦 | 刪除 |
